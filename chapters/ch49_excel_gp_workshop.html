3. Intuition & Motivation

At Scottish Widows and Lloyds Banking Group, dividend decisions are never as simple as "maximize payouts." Actuaries and risk managers sit in a boardroom balancing conflicting priorities: shareholders demand high dividends; the PRA demands high solvency coverage ratios (SCR); treasury demands liquidity; and the accounting team scrutinizes IFRS profit figures.

A standard Linear Program (LP) often fails here. If you mandate an SCR of 160% and a dividend of £1.5bn, the model might just say "Infeasible." But in the real world, management negotiates. They might accept 158% SCR if it means maintaining the dividend, or they might cut the dividend by £100m to boost liquidity. This is where Goal Programming shines. Instead of rigid constraints, we have targets and we penalize deviations based on priority.

This chapter provides the hands-on Excel architecture to build exactly these robust, boardroom-ready optimization models.

4. Formal Theory

Standard Linear Programming (Single Objective)

The standard LP formulation for our dividend optimizer is:

\[ \max_{x} \quad c^T x \] \[ \text{s.t.} \quad Ax \leq b, \quad x \geq 0 \]

Where \(x\) contains our decision variables (e.g., Dividend Amount, Hedge Ratio).

Goal Programming (Weighted)

In goal programming, hard constraints become soft targets. We introduce deviational variables \(d_i^-\) (under-achievement) and \(d_i^+\) (over-achievement). The objective is to minimize a weighted sum of unwanted deviations:

\[ \min \quad \sum_{i=1}^n (w_i^- d_i^- + w_i^+ d_i^+) \] \[ \text{s.t.} \quad f_i(x) + d_i^- - d_i^+ = T_i \quad \forall i \] \[ x, d_i^-, d_i^+ \geq 0 \]

For a target where "more is better" (e.g., Dividend, Solvency), we want to minimize \(d_i^-\). For a target where "less is better" (e.g., Hedge Cost), we minimize \(d_i^+\).

5. Worked Examples

Example 1: Single-Objective Optimization
Scottish Widows aims to maximize dividends. The initial unhedged solvency is 140%. Every 10% increase in hedge ratio increases solvency by 3% but costs £20m in liquidity. A minimum solvency of 150% is required. By setting this up as an LP, Solver finds that a 33.3% hedge ratio achieves exactly 150% solvency, maximizing the remaining liquidity for dividends.

Example 2: Goal Programming Conflict Resolution
Targets: Dividend = £1.0bn, Solvency = 160%. But current capacity only allows £0.8bn at 160% solvency, or £1.0bn at 155% solvency. If the weight on dividend shortfall is 10 and the weight on solvency shortfall is 1, the model will output £1.0bn dividend and 155% solvency. If weights are reversed, it prioritizes solvency.

Example 3: Monte Carlo Impact
If rates drop 100bps, the hedge pays off, but unhedged liabilities spike. In a 1000-path Monte Carlo simulation, we measure the 5th percentile (P5) of dividend capacity. A 50% hedge ratio might show an expected dividend of £900m but a P5 of £200m. A 100% hedge ratio might lower the expected dividend to £800m but raise the P5 to £700m, proving the value of the hedge in tail scenarios.

6. Python Code (Goal Programming with PuLP)

While this chapter focuses on Excel, here is the Python equivalent using the PuLP library for Weighted Goal Programming:

import pulp

# 1. Initialize Model
prob = pulp.LpProblem("Dividend_Goal_Programming", pulp.LpMinimize)

# 2. Decision Variables
div = pulp.LpVariable("Dividend_bn", lowBound=0, upBound=2.0)
hedge = pulp.LpVariable("Hedge_Ratio", lowBound=0, upBound=1.0)

# Deviational Variables (Under-achievement)
d_div_minus = pulp.LpVariable("d_div_minus", lowBound=0)
d_solv_minus = pulp.LpVariable("d_solv_minus", lowBound=0)

# Deviational Variables (Over-achievement - not penalized here, but needed for equality)
d_div_plus = pulp.LpVariable("d_div_plus", lowBound=0)
d_solv_plus = pulp.LpVariable("d_solv_plus", lowBound=0)

# 3. Objective (Minimize Weighted Under-achievements)
# Weights: 0.4 for Dividend, 0.6 for Solvency
prob += 0.4 * d_div_minus + 0.6 * d_solv_minus

# 4. Goals (Constraints)
# G1: Dividend >= 1.0bn
prob += div + d_div_minus - d_div_plus == 1.0

# G2: Solvency >= 160% 
# Assume Base Solvency = 140%, + 30% per full hedge, - 10% per 1bn dividend
prob += 1.40 + 0.30 * hedge - 0.10 * div + d_solv_minus - d_solv_plus == 1.60

# 5. Solve
prob.solve()

print(f"Status: {pulp.LpStatus[prob.status]}")
print(f"Optimal Dividend: £{pulp.value(div):.2f} bn")
print(f"Optimal Hedge: {pulp.value(hedge):.1%}")

Model 7: Single-Objective Dividend Optimizer (LP)

Setup:

  • B3: 0 (Decision Variable: Dividend Amount £bn)
  • B4: 0 (Decision Variable: Hedge Ratio %)
  • B7: =B3 (Objective: Maximize Dividend)

Constraint Formulas (Row 10-12):

  • B10 (Solvency Calc): =1.40 + 0.30*B4 - 0.10*B3 | D10 (Limit): 1.50
  • B11 (Liquidity Calc): =1.50 - 0.15*B4 - 0.20*B3 | D11 (Limit): 1.00
  • B12 (IFRS Earnings): =800 - 50*B4 - 100*B3 | D12 (Limit): 0

Solver Config: Data > Solver.
Set Objective: $B$7 to Max.
By Changing: $B$3:$B$4.
Constraints: Add $B$10:$B$12 >= $D$10:$D$12, Add $B$4 <= 1.
Select Solving Method: Simplex LP. Check "Make Unconstrained Variables Non-Negative".
Action: Click Solve. Generate Answer and Sensitivity Reports.

Interpretation: Look at the Sensitivity Report "Shadow Price" for the Solvency constraint. If it reads 2.0, relaxing the 1.50 limit to 1.49 allows £20m more dividend.

Model 8: Weighted Goal Programming Dividend Optimizer

Setup:

  • B3, B4: Decision Variables (Dividend, Hedge)
  • Targets (C8:C11): 1.0 (Div), 1.60 (Solv), 1.20 (Liq), 500 (IFRS)
  • Deviational Variables (Under d⁻ D8:D11, Over d⁺ E8:E11): Enter 0 in all.
  • Weights (F8:F11): 0.4, 0.3, 0.2, 0.1

Goal Equations (G8:G11):

  • G8 (Div Goal): =B3 + D8 - E8
  • G9 (Solv Goal): =(1.40+0.30*B4-0.10*B3) + D9 - E9
  • G10 (Liq Goal): =(1.50-0.15*B4-0.20*B3) + D10 - E10

Objective: B15: =SUMPRODUCT(F8:F11, D8:D11)

Solver Config: Set Objective $B$15 to Min. Changing cells: $B$3:$B$4, $D$8:$E$11. Constraints: $G$8:$G$11 = $C$8:$C$11 (Equations must equal targets). Method: Simplex LP.

Model 9: Scenario-Based Goal Programming

Expand Model 8. Instead of one set of formulas in G8:G11, create columns for Base, +100bp, -100bp.
Example for -100bp Solvency: The formula changes to reflect higher liabilities: =(1.20+0.50*B4-0.10*B3) + D_scenario - E_scenario.
The objective cell becomes the SUM of all weighted deviations across all scenarios. This yields a robust hedge/dividend combo that survives multiple stress tests.

Model 10: Monte Carlo Interest Rate Simulation

Vasicek Parameters: B1(a)=0.3, B2(b)=0.04, B3(σ)=0.01, B4(dt)=1, B5(r₀)=0.035

Path Generator (One Step):
Cell E2: =$B$5 + $B$1*($B$2-$B$5)*$B$4 + $B$3*NORMINV(RAND(),0,1)*SQRT($B$4)

Data Table Trick:

  • In G2:G1001, enter numbers 1 to 1000.
  • In H1, link to the output you want (e.g., Solvency Ratio dependent on E2). =H10 (assuming H10 calculates solvency based on rate in E2).
  • Highlight G1:H1001. Go to Data > What-If Analysis > Data Table.
  • Column input cell: pick any blank cell (e.g., Z1). Click OK.
  • Press F9. Excel recalculates RAND() 1000 times and stores the results!

Calculate =PERCENTILE(H2:H1001, 0.05) to find the P5 Worst-Case Solvency.

8. Common Mistakes & Misconceptions
  • Missing Deviational Variables: In GP, failing to include both \(d^-\) and \(d^+\) will break the equality constraint. Even if you only penalize one side, both must exist in the model.
  • Non-Linear Solver: Using GRG Nonlinear when Simplex LP is sufficient. Goal programming with absolute deviations can always be linearized using deviational variables. Simplex LP guarantees a global optimum and provides useful Shadow Prices.
  • Scaling Issues: If Dividend target is 1,000,000,000 and Solvency is 1.60, the solver will heavily skew towards solving the dividend because the absolute numerical deviation is huge. Always normalize targets (e.g., express dividends in £ billions so targets are ~1.0).
  • Data Table Recalculation: 10,000 path Data Tables can freeze Excel. Set formulas to "Automatic except for Data Tables" (Formulas > Calculation Options) while building.
9. Industry Application Box: Scottish Widows & PRA Stress Tests

At Lloyds Banking Group, dividend decisions from insurance subsidiaries like Scottish Widows to the Group centre are highly scrutinized by the Prudential Regulation Authority (PRA). The PRA doesn't just look at the base case; they look at the 1-in-200 year stress scenarios.

Using Scenario-Based Goal Programming (Model 9) is industry standard. The optimizer runs across Base, Interest Rate Up, Interest Rate Down, Credit Spread Widening, and Equity Crash simultaneously. A proposed dividend of £1bn might look great in the base case, but if it causes Solvency to breach 120% in the "Rate Down" scenario, the goal programming weights will force the model to either recommend a higher Hedge Ratio or a lower Dividend to balance the risk across all scenarios.

10. Summary & Formula Cheat-Sheet
  • Goal Equation: Formula_Cell + Under_Dev_Cell - Over_Dev_Cell = Target_Cell
  • Objective Function: =SUMPRODUCT(Weights_Range, Under_Dev_Range) (assuming targets are 'larger is better').
  • Data Table Output: =PERCENTILE(DataRange, 0.05) for Value-at-Risk / P5 metrics.
  • Solver Method: Always Simplex LP for linear goal programming.
