4. Formal Theory

Key Fixed Income Definitions

The price of a bond \( P \) with cash flows \( CF_t \) and yield to maturity \( y \) is given by:

\[ P = \sum_{t=1}^{T} \frac{CF_t}{(1+y)^t} \]

Macaulay Duration (\( D_{Mac} \)):

\[ D_{Mac} = \frac{1}{P} \sum_{t=1}^{T} \frac{t \cdot CF_t}{(1+y)^t} \]

Modified Duration (\( D_{Mod} \)):

\[ D_{Mod} = \frac{D_{Mac}}{1+y} \]

Dollar Value of a Basis Point (DV01):

\[ DV01 = P \times D_{Mod} \times 0.0001 \]

Taylor Series Expansion for Price Changes:

\[ \Delta P \approx -P \cdot D_{Mod} \cdot \Delta y + \frac{1}{2} P \cdot Convexity \cdot (\Delta y)^2 \]

5. Worked Examples

Example 1: Scottish Widows Annuity Book Sensitivity

Suppose an annuity liability book has a present value of £10 billion and a Modified Duration of 12. If the yield curve shifts upward by 50 basis points (\( \Delta y = +0.0050 \)):

\[ \Delta P \approx - £10,000,000,000 \times 12 \times 0.0050 = -£600,000,000 \]

The liability drops by £600 million. If the matching asset portfolio has a duration of 10 and PV of £10.5 billion, the asset value drops by:

\[ \Delta Asset \approx - £10,500,000,000 \times 10 \times 0.0050 = -£525,000,000 \]

Net impact on Own Funds = \(-525 - (-600) = +£75\) million. Understanding this basic mismatch is critical before recommending dividend payouts.

6. Python Code

While we build in Excel, production systems often use Python. Here are equivalent implementations of the core logic using numpy and pandas.


import numpy as np
import pandas as pd
import numpy_financial as npf

def bond_pricer(face_value, coupon_rate, yield_to_maturity, maturity):
    cf = np.full(maturity, face_value * coupon_rate)
    cf[-1] += face_value
    times = np.arange(1, maturity + 1)
    
    discount_factors = 1 / (1 + yield_to_maturity)**times
    price = np.sum(cf * discount_factors)
    
    mac_dur = np.sum(times * cf * discount_factors) / price
    mod_dur = mac_dur / (1 + yield_to_maturity)
    dv01 = price * mod_dur * 0.0001
    
    return {'Price': price, 'Mac_Duration': mac_dur, 'Mod_Duration': mod_dur, 'DV01': dv01}

# Example usage matching our Excel Model 1
result = bond_pricer(100, 0.05, 0.04, 10)
print(f"Price: {result['Price']:.2f}, Mod Dur: {result['Mod_Duration']:.2f}")

# Model 6: Dividend Capacity Calculator Logic
def dividend_capacity(own_funds, scr, target_ratio, liquidity, min_liquidity):
    required_capital = scr * target_ratio
    capital_buffer = max(0, own_funds - required_capital)
    liquidity_buffer = max(0, liquidity - min_liquidity)
    return min(capital_buffer, liquidity_buffer)

7. Excel Implementation (Step-by-Step)

Below are detailed instructions for building six fundamental ALM and interest rate models.

Model 1: Bond Pricer & Duration Dashboard

  1. In A1, type Bond Pricer. In B1, type Inputs.
  2. In A3: Coupon Rate; B3: 5%
  3. In A4: Face Value; B4: 100
  4. In A5: Maturity (years); B5: 10
  5. In A6: Yield (YTM); B6: 4%
  6. In A8: Results:
  7. In A9: Bond Price; B9: =PV(B6, B5, B4*B3, B4) * -1 (or manual DCF sum)
  8. In A10: Macaulay Duration. To calculate this simply without a cash flow schedule, use: =((1+B6)/B6) - ( (1+B6) + B5*(B3-B6) ) / ( B3*((1+B6)^B5 - 1) + B6 ) in B10.
  9. In A11: Modified Duration; B11: =B10/(1+B6)
  10. In A12: DV01; B12: =B9*B11*0.0001
  11. Sensitivity Table: In D2:K2, enter yields: 1%, 2%, 3%, 4%, 5%, 6%, 7%, 8%. In C3, enter =B9. Highlight C2:K3, go to Data -> What-If Analysis -> Data Table. Leave Row input cell blank, set Row input cell to $B$6. The table will populate with prices.
  12. Chart: Highlight the yields (D2:K2) and the resulting prices (D3:K3). Insert a Scatter with Smooth Lines chart to visualize the convex Price-Yield curve.

Model 2: Yield Curve Builder

  1. Inputs: In A3:B8, enter benchmark gilt yields (e.g., 2Y=3.5%, 5Y=3.7%, 10Y=4.0%, 20Y=4.2%, 30Y=4.1%, 50Y=3.9%).
  2. Interpolation: Set up a continuous column of years (1 to 50) in D3:D52. Use =FORECAST.LINEAR or a custom linear interpolation formula in E3:E52 to fill in par yields for missing years based on A3:B8.
  3. Bootstrapping Spot Rates: In F3 (Year 1), spot = par yield = E3. In F4 (Year 2), the formula to extract the spot rate \(S_2\) from the 2-yr par bond trading at par (100) is =((1+E4)/(1-E4/(1+F$3)))^(1/2)-1 (simplified for annual coupons). Drag this down to build the spot curve.
  4. Forward Rates: In G4 (1Y1Y Forward), use =((1+F4)^D4 / (1+F3)^D3) - 1.
  5. Charting: Select Columns D (Years), E (Par), F (Spot), and G (Forward). Insert a Line Chart to show par vs spot vs forward curves.

Model 3: Portfolio Duration & Convexity

  1. Create a table of 10 bonds (Columns A: Bond ID, B: Market Value, C: Mod Duration, D: Convexity).
  2. At the bottom (Row 15), sum the Market Value: =SUM(B2:B11).
  3. In Column E (Weight), calculate =B2/$B$15.
  4. In Cell B16 (Portfolio Duration): =SUMPRODUCT(E2:E11, C2:C11).
  5. In Cell B17 (Portfolio Convexity): =SUMPRODUCT(E2:E11, D2:D11).
  6. Data Table (ΔPortfolio Value): Set up shifts (+/- 25, 50, 100 bps) in Row 20. In Cell A21, link the Taylor expansion formula referencing portfolio PV, Dur, Conv, and the shift. Highlight and create a Data Table.

Model 4: ALM Mismatch Dashboard

  1. Column A: Year (1 to 30)
  2. Column B: Asset CFs (e.g., coupon and principal payments)
  3. Column C: Liability CFs (e.g., projected annuity payments)
  4. Column D: Mismatch =B2-C2
  5. PV Calculation: In Cell F1, set a flat discount rate (e.g., 4%). Create columns for PV of Assets and PV of Liabs using =B2/(1+$F$1)^A2.
  6. Duration Gap: Calculate MAC Duration for Assets and Liabilities using the time-weighted PV formulas. Duration Gap = Asset Duration - Liability Duration.
  7. Waterfall Chart: Select the Mismatch column (D). Insert a Waterfall Chart. This visually demonstrates the timing risk: e.g., excess cash in years 1-10, shortfall in years 11-20.

Model 5: Simplified Insurance Balance Sheet Simulator

  1. Assets: Base PV in B3. Mod Duration in B4. Convexity in B5.
  2. Liabilities: Base PV in B8. Mod Duration in B9. Convexity in B10.
  3. Capital (Own Funds): In B12: =B3-B8.
  4. SCR: In B13 (hardcode for simplicity, e.g., 500).
  5. Solvency Ratio: In B14: =B12/B13.
  6. Shock Selector: In E2, create a Data Validation dropdown with values: -2%, -1%, -0.5%, 0%, 0.5%, 1%, 2%.
  7. Shocked Values: In C3 (Shocked Assets), use the Taylor formula: =B3 * (1 - B4*E2 + 0.5*B5*E2^2). Repeat for Liabilities in C8.
  8. Shocked Solvency Ratio: In C14: =(C3-C8)/B13.
  9. Conditional Formatting: On C14, go to Conditional Formatting -> Highlight Cell Rules. Greater than 1.5 -> Green. Between 1.3 and 1.5 -> Amber. Less than 1.3 -> Red.

Model 6: Dividend Capacity Calculator

  1. Inputs: Own Funds (B2 = Model 5 C12), SCR (B3), Target Solvency Ratio (B4 = 140%), Available Liquidity (B5), Minimum Liquidity Constraint (B6).
  2. Required Capital: In B8: =B3 * B4.
  3. Capital Buffer: In B9: =MAX(0, B2 - B8).
  4. Liquidity Buffer: In B10: =MAX(0, B5 - B6).
  5. Max Distributable Amount: In B12: =MIN(B9, B10).
  6. Analysis: Link B12 to a Data Table where the column input is the interest rate shock from Model 5. This shows how dividend capacity dynamically shrinks if rates fall and liabilities expand faster than assets!
8. Common Mistakes & Misconceptions
  • Confusing Macaulay and Modified Duration: Macaulay is measured in years (time center of mass); Modified is a price sensitivity measure (percentage change). You must divide Mac by (1+y) to get Mod.
  • Ignoring Convexity for Large Shocks: For a 5bp move, Duration is sufficient. For a 200bp shock (common in PRA stress tests), ignoring the 0.5 * Convexity * (dy)^2 term leads to massive errors in Solvency II capital estimation.
  • Sign Errors in Taylor Expansion: Remember that Price moves inversely to Yields. The term is - Duration * dy.
  • Data Table Calculation Options: Excel defaults to "Automatic except for Data Tables" on large models to save compute time. If your table shows all the same numbers, press F9 or change calculation options!

10. Summary & Formula Cheat-Sheet

  • Macaulay Duration: MACD(CF, y) = sum(t*CF_t / (1+y)^t) / Price
  • Modified Duration: MODD = MACD / (1+y)
  • DV01: Price * MODD * 0.0001
  • Solvency Ratio: Own Funds / SCR
  • Max Dividend: MIN(Own Funds - (SCR * Target%), Liquidity - Min_Liquidity)
