1. Intuition & Motivation

In finance and actuarial science, we rarely analyze a single asset or risk in isolation. A pension fund manager oversees thousands of different equities, bonds, and alternative investments. An insurance actuary evaluates policies across multiple intertwined demographic and geographic segments. If we try to model these using standard scalar algebra, we quickly drown in a sea of subscripts and summation signs.

Linear algebra is the mathematical language of high-dimensional spaces. By organizing data into vectors and matrices, we can perform complex operations simultaneously across all assets. For instance, calculating the overall risk (variance) of a portfolio of 500 stocks requires considering 500 individual variances and 124,750 pairwise correlations. Matrix multiplication reduces this massive calculation to a single, elegant equation: \(\sigma^2_p = \mathbf{w}^T \Sigma \mathbf{w}\). Linear algebra not only simplifies notation but also reveals deep geometric relationships in the data, such as identifying the latent factors driving the bond market through Principal Component Analysis.

2. Formal Theory

2.1 Vectors

Definition 3.1: Vector

A column vector \(\mathbf{x} \in \R^n\) is an ordered list of \(n\) real numbers:

\[ \mathbf{x} = \begin{bmatrix} x_1 \\ x_2 \\ \vdots \\ x_n \end{bmatrix} \]

The elements \(x_i\) are the components of the vector.

Vectors support two primary operations: scalar multiplication (\(c\mathbf{x}\) multiplies each element by a scalar \(c\)) and vector addition (\(\mathbf{x} + \mathbf{y}\) adds corresponding elements). A set of vectors is linearly independent if no vector in the set can be written as a linear combination of the others.

The dot product (or inner product) of two vectors \(\mathbf{x}, \mathbf{y} \in \R^n\) is the scalar sum of the products of their corresponding entries: \(\mathbf{x}^T \mathbf{y} = \sum_{i=1}^n x_i y_i\). It measures alignment. The Euclidean norm (length) is \(\|\mathbf{x}\| = \sqrt{\mathbf{x}^T \mathbf{x}}\). The angle \(\theta\) between two vectors satisfies \(\cos(\theta) = \frac{\mathbf{x}^T \mathbf{y}}{\|\mathbf{x}\| \|\mathbf{y}\|}\).

2.2 Matrices

Definition 3.2: Matrix

A matrix \(A \in \R^{m \times n}\) is a rectangular array of real numbers with \(m\) rows and \(n\) columns. The element in the \(i\)-th row and \(j\)-th column is denoted \(a_{ij}\).

The transpose \(A^T\) swaps rows and columns. A matrix is symmetric if \(A = A^T\). An orthogonal matrix \(Q\) satisfies \(Q^T Q = Q Q^T = I\), meaning its columns are mutually perpendicular unit vectors.

2.3 Systems of Linear Equations

A system of \(m\) linear equations in \(n\) variables can be written compactly as \(A\mathbf{x} = \mathbf{b}\). We solve this using Gaussian elimination to reduce the augmented matrix \([A | \mathbf{b}]\) to row echelon form. The rank of \(A\) is the number of linearly independent rows (or columns). A unique solution exists if and only if \(A\) is square (\(n=n\)) and has full rank (\(\text{rank}(A) = n\)).

2.4 Determinants

The determinant, \(\det(A)\) or \(|A|\), is a scalar value defined only for square matrices. Geometrically, the absolute value of the determinant represents the volume of the parallelepiped spanned by the matrix's column vectors. A matrix is invertible if and only if \(\det(A) \neq 0\).

2.5 Matrix Inverse

For a square matrix \(A\), if there exists a matrix \(A^{-1}\) such that \(AA^{-1} = A^{-1}A = I\), then \(A^{-1}\) is the inverse of \(A\). The solution to \(A\mathbf{x} = \mathbf{b}\) is simply \(\mathbf{x} = A^{-1}\mathbf{b}\).

2.6 Eigenvalues and Eigenvectors

Definition 3.3: Eigenvalues and Eigenvectors

For a square matrix \(A\), a non-zero vector \(\mathbf{v}\) is an eigenvector with corresponding scalar eigenvalue \(\lambda\) if:

\[ A\mathbf{v} = \lambda \mathbf{v} \]

This means the matrix \(A\) acts on the vector \(\mathbf{v}\) simply by stretching or shrinking it by a factor of \(\lambda\), without changing its direction. We find eigenvalues by solving the characteristic equation \(\det(A - \lambda I) = 0\).

Theorem 3.1: Spectral Theorem for Symmetric Matrices

If \(A\) is a real symmetric matrix (\(A = A^T\)), then its eigenvalues are real, and there exists an orthogonal matrix \(Q\) such that \(A = Q \Lambda Q^T\), where \(\Lambda\) is a diagonal matrix of the eigenvalues.

2.7 Positive-Definite Matrices

Definition 3.4: Positive (Semi-)Definite Matrix

A symmetric matrix \(A \in \R^{n \times n}\) is positive definite (PD) if for all non-zero vectors \(\mathbf{x} \in \R^n\):

\[ \mathbf{x}^T A \mathbf{x} > 0 \]

It is positive semi-definite (PSD) if \(\mathbf{x}^T A \mathbf{x} \geq 0\).

In finance, a covariance matrix \(\Sigma\) must be PSD. Why? Because the variance of any portfolio with weights \(\mathbf{w}\) is \(\mathbf{w}^T \Sigma \mathbf{w}\), and variance cannot be negative. If \(\Sigma\) is not PSD, there exists a portfolio with negative variance, which is impossible.

2.8 Matrix Decompositions

Cholesky Decomposition: Every positive definite matrix \(A\) can be factored as \(A = L L^T\), where \(L\) is a lower triangular matrix with positive diagonal entries. This is the matrix equivalent of a square root.

Singular Value Decomposition (SVD): Any rectangular matrix \(A \in \R^{m \times n}\) can be factored as \(A = U \Sigma V^T\), where \(U\) and \(V\) are orthogonal matrices and \(\Sigma\) is a diagonal matrix of singular values.

2.9 Principal Component Analysis (PCA)

PCA transforms a set of correlated variables into a set of linearly independent variables called principal components. Given a covariance matrix \(\Sigma\), we perform the eigendecomposition \(\Sigma = Q \Lambda Q^T\). The eigenvectors (columns of \(Q\)) are the principal axes, and the eigenvalues (diagonal elements of \(\Lambda\)) represent the variance explained by each component.

2.10 Matrix Calculus for Finance

When optimizing portfolios, we need to take derivatives with respect to vectors. The gradient of the linear function \(f(\mathbf{w}) = \mathbf{c}^T \mathbf{w}\) is \(\nabla_\mathbf{w} f = \mathbf{c}\). The gradient of the quadratic form (portfolio variance) \(f(\mathbf{w}) = \mathbf{w}^T \Sigma \mathbf{w}\) is:

\[ \nabla_\mathbf{w} (\mathbf{w}^T \Sigma \mathbf{w}) = 2 \Sigma \mathbf{w} \]

3. Worked Examples

Example 3.1: Computing Portfolio Variance

Consider a 3-asset portfolio with weights \(\mathbf{w} = \begin{bmatrix} 0.4 \\ 0.35 \\ 0.25 \end{bmatrix}\). The asset volatilities are \(\sigma_1 = 0.15\), \(\sigma_2 = 0.20\), \(\sigma_3 = 0.25\). The correlation matrix is:

\[ C = \begin{bmatrix} 1.0 & 0.4 & -0.2 \\ 0.4 & 1.0 & 0.5 \\ -0.2 & 0.5 & 1.0 \end{bmatrix} \]

Step 1: Construct the covariance matrix \(\Sigma\). We know \(\Sigma_{ij} = \sigma_i \sigma_j C_{ij}\).

\[ \Sigma = \begin{bmatrix} 0.15 & 0 & 0 \\ 0 & 0.20 & 0 \\ 0 & 0 & 0.25 \end{bmatrix} \begin{bmatrix} 1.0 & 0.4 & -0.2 \\ 0.4 & 1.0 & 0.5 \\ -0.2 & 0.5 & 1.0 \end{bmatrix} \begin{bmatrix} 0.15 & 0 & 0 \\ 0 & 0.20 & 0 \\ 0 & 0 & 0.25 \end{bmatrix} \] \[ \Sigma = \begin{bmatrix} 0.0225 & 0.0120 & -0.0075 \\ 0.0120 & 0.0400 & 0.0250 \\ -0.0075 & 0.0250 & 0.0625 \end{bmatrix} \]

Step 2: Calculate \(\sigma^2_p = \mathbf{w}^T \Sigma \mathbf{w}\).

\[ \Sigma \mathbf{w} = \begin{bmatrix} 0.0225 & 0.0120 & -0.0075 \\ 0.0120 & 0.0400 & 0.0250 \\ -0.0075 & 0.0250 & 0.0625 \end{bmatrix} \begin{bmatrix} 0.4 \\ 0.35 \\ 0.25 \end{bmatrix} = \begin{bmatrix} 0.011325 \\ 0.025050 \\ 0.021375 \end{bmatrix} \] \[ \sigma^2_p = \begin{bmatrix} 0.4 & 0.35 & 0.25 \end{bmatrix} \begin{bmatrix} 0.011325 \\ 0.025050 \\ 0.021375 \end{bmatrix} = 0.00453 + 0.0087675 + 0.00534375 = 0.01864125 \]

The portfolio variance is 0.0186, giving a volatility of \(\sqrt{0.01864125} \approx 13.65\%\).

Example 3.2: Eigenvalues of a 2x2 Covariance Matrix

Let a 2-asset covariance matrix be \(\Sigma = \begin{bmatrix} 0.04 & 0.02 \\ 0.02 & 0.05 \end{bmatrix}\). Find the eigenvalues.

Step 1: Set up the characteristic equation \(\det(\Sigma - \lambda I) = 0\).

\[ \det \begin{bmatrix} 0.04 - \lambda & 0.02 \\ 0.02 & 0.05 - \lambda \end{bmatrix} = (0.04 - \lambda)(0.05 - \lambda) - (0.02)^2 = 0 \] \[ \lambda^2 - 0.09\lambda + 0.0020 - 0.0004 = 0 \implies \lambda^2 - 0.09\lambda + 0.0016 = 0 \]

Step 2: Solve using the quadratic formula.

\[ \lambda = \frac{0.09 \pm \sqrt{(-0.09)^2 - 4(1)(0.0016)}}{2} = \frac{0.09 \pm \sqrt{0.0081 - 0.0064}}{2} = \frac{0.09 \pm \sqrt{0.0017}}{2} \] \[ \lambda_1 \approx \frac{0.09 + 0.04123}{2} = 0.0656, \quad \lambda_2 \approx \frac{0.09 - 0.04123}{2} = 0.0244 \]

The first principal component explains \(0.0656 / (0.0656 + 0.0244) = 72.9\%\) of the variance.

Example 3.3: Cholesky Decomposition for Simulation

We need to simulate correlated random variables with correlation matrix \(C = \begin{bmatrix} 1.0 & 0.6 \\ 0.6 & 1.0 \end{bmatrix}\). We find the Cholesky factor \(L\) such that \(L L^T = C\).

\[ \begin{bmatrix} l_{11} & 0 \\ l_{21} & l_{22} \end{bmatrix} \begin{bmatrix} l_{11} & l_{21} \\ 0 & l_{22} \end{bmatrix} = \begin{bmatrix} l_{11}^2 & l_{11}l_{21} \\ l_{21}l_{11} & l_{21}^2 + l_{22}^2 \end{bmatrix} = \begin{bmatrix} 1.0 & 0.6 \\ 0.6 & 1.0 \end{bmatrix} \]

Solving term by term:

  • \(l_{11}^2 = 1.0 \implies l_{11} = 1.0\)
  • \(l_{11}l_{21} = 0.6 \implies (1.0)l_{21} = 0.6 \implies l_{21} = 0.6\)
  • \(l_{21}^2 + l_{22}^2 = 1.0 \implies 0.36 + l_{22}^2 = 1.0 \implies l_{22}^2 = 0.64 \implies l_{22} = 0.8\)
\[ L = \begin{bmatrix} 1.0 & 0 \\ 0.6 & 0.8 \end{bmatrix} \]

To simulate correlated returns, draw independent standard normals \(z_1, z_2\). The correlated variables are \(x_1 = z_1\) and \(x_2 = 0.6z_1 + 0.8z_2\).

Example 3.4: Solving Immunization Constraints

A life insurer needs to construct a bond portfolio matching the present value (\(V = \$100 \text{M}\)) and duration (\(D = 8.5 \text{ yrs}\)) of liabilities. They have cash to allocate across a 5-yr bond (\(D_1 = 4.2\)) and a 10-yr bond (\(D_2 = 8.9\)). Let \(w_1, w_2\) be the portfolio weights.

Constraints:

  • Weights sum to 1: \(w_1 + w_2 = 1\)
  • Match duration: \(4.2w_1 + 8.9w_2 = 8.5\)

Matrix form \(A\mathbf{w} = \mathbf{b}\):

\[ \begin{bmatrix} 1 & 1 \\ 4.2 & 8.9 \end{bmatrix} \begin{bmatrix} w_1 \\ w_2 \end{bmatrix} = \begin{bmatrix} 1 \\ 8.5 \end{bmatrix} \]

Calculate \(A^{-1}\): \(\det(A) = (1)(8.9) - (1)(4.2) = 4.7\).

\[ A^{-1} = \frac{1}{4.7} \begin{bmatrix} 8.9 & -1 \\ -4.2 & 1 \end{bmatrix} \] \[ \mathbf{w} = A^{-1}\mathbf{b} = \frac{1}{4.7} \begin{bmatrix} 8.9 & -1 \\ -4.2 & 1 \end{bmatrix} \begin{bmatrix} 1 \\ 8.5 \end{bmatrix} = \frac{1}{4.7} \begin{bmatrix} 8.9 - 8.5 \\ -4.2 + 8.5 \end{bmatrix} = \frac{1}{4.7} \begin{bmatrix} 0.4 \\ 4.3 \end{bmatrix} \approx \begin{bmatrix} 0.085 \\ 0.915 \end{bmatrix} \]

The insurer must invest 8.5% in the 5-yr bond and 91.5% in the 10-yr bond.

Example 3.5: PCA on the Yield Curve

An analyst extracts the covariance matrix \(\Sigma\) of daily changes in the 1y, 5y, and 10y Treasury yields. After eigendecomposition, they find the following eigenvalues (\(\lambda_i\)) and eigenvectors (\(\mathbf{v}_i\)):

\(\lambda_1 = 8.5, \mathbf{v}_1 = [0.55, 0.58, 0.60]^T\) (Level: all maturities move up together)

\(\lambda_2 = 1.2, \mathbf{v}_2 = [-0.71, -0.05, 0.70]^T\) (Slope: short end falls, long end rises)

\(\lambda_3 = 0.3, \mathbf{v}_3 = [0.44, -0.81, 0.38]^T\) (Curvature: wings rise, belly falls)

Variance Explained: Total variance = \(8.5 + 1.2 + 0.3 = 10.0\).

The first principal component (Level) explains \(8.5 / 10.0 = 85\%\) of the yield curve dynamics. The first two components explain \(97\%\).

4. Python Code

The following Python code reproduces the portfolio variance computation (Example 3.1) and the eigendecomposition (Example 3.2) using NumPy, the standard library for linear algebra in Python.

import numpy as np

# --- Example 3.1: Portfolio Variance ---
weights = np.array([0.4, 0.35, 0.25])
vols = np.array([0.15, 0.20, 0.25])
corr_matrix = np.array([
    [1.0, 0.4, -0.2],
    [0.4, 1.0, 0.5],
    [-0.2, 0.5, 1.0]
])

# Compute covariance matrix: diag(vols) * corr * diag(vols)
diag_vols = np.diag(vols)
cov_matrix = diag_vols @ corr_matrix @ diag_vols
print("Covariance Matrix:\n", np.round(cov_matrix, 4))

# Compute portfolio variance: w.T * Cov * w
port_var = weights.T @ cov_matrix @ weights
print(f"\nPortfolio Variance: {port_var:.6f}")
print(f"Portfolio Volatility: {np.sqrt(port_var):.4%}")

# --- Example 3.2: Eigendecomposition ---
Sigma_2x2 = np.array([
    [0.04, 0.02],
    [0.02, 0.05]
])

eigenvalues, eigenvectors = np.linalg.eigh(Sigma_2x2)
# Note: eigh is optimized for symmetric matrices

print(f"\nEigenvalues: {np.round(eigenvalues, 4)}")
total_var = np.sum(eigenvalues)
print(f"Variance explained by PC1: {eigenvalues[1]/total_var:.2%}") 
# eigh sorts eigenvalues in ascending order, so index 1 is the largest.

6. Common Mistakes & Misconceptions

Watch Out!
  • Commutativity Assumption: Assuming \(AB = BA\). In general, matrix multiplication is not commutative. The order of multiplication is crucial.
  • Matrix Inverse Exists for All: Attempting to invert a non-square matrix, or a square matrix with a determinant of zero (singular matrix). Use the pseudoinverse (via SVD) for non-invertible or rectangular matrices.
  • Confusing PSD with all Positive Elements: A matrix can have negative off-diagonal elements and still be Positive Definite (like the covariance matrix in Example 3.1). Conversely, a matrix with all positive elements can be non-PD if the correlations are mathematically inconsistent.
  • Eigenvalue Sorting: When extracting eigenvalues from software libraries (like Python's np.linalg.eig), they are not always sorted by magnitude. Always sort them descending to identify the primary principal components.

7. Industry Application Box

Application: Quantitative Asset Management (Risk Models)

In large-scale quantitative funds, estimating a robust covariance matrix for thousands of stocks is computationally difficult and statistically noisy. If you have 3000 stocks, the covariance matrix has \(\approx 4.5\) million unique entries. If you only use 5 years of daily data (1250 days), the matrix will be singular (non-invertible) because the number of observations is less than the number of variables.

Quants solve this using Factor Models and Matrix Factorization. Instead of modeling the full \(3000 \times 3000\) covariance matrix directly, they use PCA to identify, say, 50 latent factors driving the market. The covariance matrix is then approximated as \(\Sigma \approx B F B^T + D\), where \(B\) is the \(3000 \times 50\) matrix of factor loadings, \(F\) is the \(50 \times 50\) factor covariance matrix, and \(D\) is a diagonal matrix of idiosyncratic stock risk. This matrix algebraic trick reduces the parameters to estimate from millions down to a few thousand, ensuring the matrix is invertible and robust out-of-sample.

8. Summary & Formula Cheat-Sheet

Formula Cheat-Sheet
  • Dot Product: \(\mathbf{x}^T \mathbf{y} = \sum x_i y_i = \|\mathbf{x}\|\|\mathbf{y}\|\cos(\theta)\)
  • Matrix Multiplication: \((AB)_{ij} = \sum_{k} A_{ik} B_{kj}\)
  • Transpose Properties: \((AB)^T = B^T A^T\)
  • Inverse Properties: \((AB)^{-1} = B^{-1} A^{-1}\), \((A^T)^{-1} = (A^{-1})^T\)
  • Portfolio Variance: \(\sigma^2_p = \mathbf{w}^T \Sigma \mathbf{w}\)
  • Characteristic Equation: \(\det(A - \lambda I) = 0\)
  • Spectral Decomposition: \(A = Q \Lambda Q^T\) (for symmetric \(A\))
  • Gradient of Quadratic Form: \(\nabla_\mathbf{x} (\mathbf{x}^T A \mathbf{x}) = (A + A^T)\mathbf{x} = 2A\mathbf{x}\) (if \(A\) is symmetric)

3.12 Let \(X\) be an \(m \times n\) matrix of mean-centered returns (m assets, n time periods). The covariance matrix is \(\Sigma = \frac{1}{n-1}XX^T\). Prove that \(\Sigma\) is always positive semi-definite.

Selected Solutions

Solution 3.1: \(\mathbf{u}^T \mathbf{v} = (2)(4) + (-1)(2) + (3)(-1) = 8 - 2 - 3 = 3\).
\(\|\mathbf{u}\| = \sqrt{4+1+9} = \sqrt{14}\). \(\|\mathbf{v}\| = \sqrt{16+4+1} = \sqrt{21}\).
\(\cos(\theta) = \frac{3}{\sqrt{14}\sqrt{21}} \implies \theta \approx 79.9^\circ\).

Solution 3.3: \(\det(A) = (5)(1) - (2)(2) = 1\).
\(A^{-1} = \frac{1}{1} \begin{bmatrix} 1 & -2 \\ -2 & 5 \end{bmatrix} = \begin{bmatrix} 1 & -2 \\ -2 & 5 \end{bmatrix}\).

Solution 3.4: \(\sigma^2 = \begin{bmatrix} 0.6 & 0.4 \end{bmatrix} \begin{bmatrix} 0.04 & 0.01 \\ 0.01 & 0.09 \end{bmatrix} \begin{bmatrix} 0.6 \\ 0.4 \end{bmatrix}\).
\(\Sigma \mathbf{w} = \begin{bmatrix} 0.024 + 0.004 \\ 0.006 + 0.036 \end{bmatrix} = \begin{bmatrix} 0.028 \\ 0.042 \end{bmatrix}\).
\(\sigma^2 = 0.6(0.028) + 0.4(0.042) = 0.0168 + 0.0168 = 0.0336\).

Solution 3.6: Let \(L = \begin{bmatrix} l_{11} & 0 \\ l_{21} & l_{22} \end{bmatrix}\).
\(l_{11}^2 = 4 \implies l_{11} = 2\).
\(l_{11}l_{21} = 2 \implies 2l_{21} = 2 \implies l_{21} = 1\).
\(l_{21}^2 + l_{22}^2 = 10 \implies 1 + l_{22}^2 = 10 \implies l_{22} = 3\).
\(L = \begin{bmatrix} 2 & 0 \\ 1 & 3 \end{bmatrix}\).

Solution 3.8: By definition, \(A\mathbf{v} = \lambda\mathbf{v}\). Multiply both sides by \(A^{-1}\):
\(A^{-1}A\mathbf{v} = A^{-1}(\lambda\mathbf{v}) \implies \mathbf{v} = \lambda(A^{-1}\mathbf{v})\).
Divide by \(\lambda\) (since \(A\) is invertible, \(\lambda \neq 0\)): \(A^{-1}\mathbf{v} = \frac{1}{\lambda}\mathbf{v}\). Thus \(\lambda^{-1}\) is an eigenvalue of \(A^{-1}\).

Solution 3.9: \(L(\mathbf{w}, \lambda) = \frac{1}{2} \mathbf{w}^T \Sigma \mathbf{w} - \lambda(\mathbf{w}^T \mathbf{1} - 1)\).
Take derivative w.r.t \(\mathbf{w}\): \(\nabla_{\mathbf{w}} L = \Sigma \mathbf{w} - \lambda \mathbf{1} = 0 \implies \mathbf{w} = \lambda \Sigma^{-1} \mathbf{1}\).
Multiply by \(\mathbf{1}^T\): \(\mathbf{1}^T \mathbf{w} = \lambda \mathbf{1}^T \Sigma^{-1} \mathbf{1}\).
Since \(\mathbf{1}^T \mathbf{w} = 1\), we have \(\lambda = \frac{1}{\mathbf{1}^T \Sigma^{-1} \mathbf{1}}\).
Therefore, \(\mathbf{w}^* = \frac{\Sigma^{-1} \mathbf{1}}{\mathbf{1}^T \Sigma^{-1} \mathbf{1}}\).

Solution 3.12: Let \(\mathbf{y}\) be any non-zero vector in \(\R^m\).
We want to show \(\mathbf{y}^T \Sigma \mathbf{y} \geq 0\).
\(\mathbf{y}^T (\frac{1}{n-1}XX^T) \mathbf{y} = \frac{1}{n-1} (\mathbf{y}^T X) (X^T \mathbf{y})\).
Let \(\mathbf{z} = X^T \mathbf{y}\). Then \(\mathbf{y}^T X = (X^T \mathbf{y})^T = \mathbf{z}^T\).
The expression becomes \(\frac{1}{n-1} \mathbf{z}^T \mathbf{z} = \frac{1}{n-1} \|\mathbf{z}\|^2\).
Since the squared norm of any real vector is non-negative, \(\|\mathbf{z}\|^2 \geq 0\). Therefore \(\Sigma\) is PSD.
